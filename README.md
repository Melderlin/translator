# Глоссарии переводчика (EN → RU)

Статический сайт на HTML, CSS и ES5 JavaScript для медицинского переводчика. Интерфейс рассчитан на старый iPad 3 с iOS 9 Safari: крупные кнопки, читаемый текст, Flexbox с префиксами WebKit, без тяжёлых библиотек и с масштабированием pinch-to-zoom.

## Адрес сайта

После включения GitHub Pages сайт будет доступен по адресу:

https://melderlin.github.io/translator/

Для публикации откройте Settings → Pages, выберите Deploy from a branch, ветку main и папку /(root), затем нажмите Save. Ссылка заработает после завершения публикации GitHub Pages.

## Как открыть сайт на iPad

1. Откройте Safari на iPad и перейдите по HTTPS-адресу выше.
2. При первом открытии загружаются HTML, CSS, JavaScript и data/glossaries.json.
3. Выбирайте глоссарий или тег, ищите английские и русские слова, открывайте карточки и связанные термины.
4. Масштабируйте страницу жестом двумя пальцами. Кнопка Назад в Safari возвращает к предыдущему фильтру или термину.

Не открывайте index.html через file://: браузер может запрещать XMLHttpRequest к локальным файлам.

## Как добавить глоссарий

Откройте data/glossaries.json и добавьте объект в массив glossaries, например:

    {"id":"neurology","name_en":"Neurology","name_ru":"Неврология"}

Затем добавьте ID словаря и русское/английское название в функцию glossaryLabel и массив отображаемых словарей в app.js. Используйте уникальный ID в нижнем регистре.

## Как добавить термин

Добавьте объект в массив terms в data/glossaries.json со всеми полями:

    {
      "id": "neurology:neuron",
      "glossary": "neurology",
      "term_en": "neuron",
      "term_ru": "нейрон",
      "definition_ru": "Нервная клетка, способная воспринимать и передавать сигналы.",
      "tags": ["anatomy", "nervous system"],
      "related": ["anatomy:myocardium"]
    }

ID должен быть уникальным. Поле glossary должно совпадать с ID словаря. Все поля обязательны; tags и related — массивы строк. JSON использует двойные кавычки и не должен содержать запятых после последних элементов.

## Теги и related-ссылки

Теги — обычные строки. Совпадающее написание означает общий тег: heart показывает термины из Anatomy, Pathology и Pharmacology. Выбор тега глобальный, он ищет по всем словарям независимо от текущего раздела.

В related записываются ID других терминов, например anatomy:myocardium и pathology:myocardial_infarction. Для взаимной навигации укажите ссылки с обеих сторон. Проверяйте, что каждый ID существует.

## Проверка отсутствия сетевых запросов при фильтрации

1. Откройте сайт в Chrome с DevTools или Safari Web Inspector на Mac, подключив iPad кабелем.
2. Откройте вкладку Network до загрузки сайта и перезагрузите страницу один раз. В начальной загрузке должны быть index.html, style.css, app.js и один запрос data/glossaries.json.
3. Не перезагружая страницу, выберите heart, переключите глоссарий, выполните поиск и откройте связанный термин.
4. Проверьте Network: новые строки запросов появляться не должны. Фильтрация выполняется над данными, которые уже находятся в памяти; hash меняется на клиенте без перезагрузки документа.

Сайт не использует fetch, Service Workers, внешние CDN, шрифты, изображения, API или сторонние библиотеки. При полном повторном открытии сайта браузер может загрузить файлы заново.
