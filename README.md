# Translator Dream Tool — медицинский глоссарий EN–RU

Сайт: https://melderlin.github.io/translator/  
Репозиторий: https://github.com/Melderlin/translator

## Для чего он сделан

Инструмент рассчитан на живой перевод лекции. Вместо поиска и большого облака тегов основной сценарий теперь такой:

1. Нажать цветной раздел.
2. Нажать букву английского термина.
3. Найти слово в коротком списке и нажать на строку.
4. Прочитать перевод, подсказку произношения и определение.
5. При необходимости открыть связанный термин — в том числе из другого раздела.

Есть режим «Все термины» для просмотра по алфавиту и цветовые метки, чтобы раздел был заметен сразу. Меню разделов продублировано внизу. Теги показываются компактно только внутри открытой записи; нажатие на тег показывает связанные записи из всех разделов.

## Разделы и данные

В данных 309 терминов из лекции о женской репродуктивной системе, 8 разделов и 79 тегов. Существующие глоссарии и их записи хранятся в \`data/terms/\`; не меняйте их только ради редизайна.

Файл \`data/glossaries.json\` — манифест разделов и файлов:

- \`glossaries\`: ID и названия разделов.
- \`term_files\`: относительные пути к JSON-массивам с терминами.

## Как добавить термин

1. Откройте папку \`data/terms/\` и выберите файл нужного раздела.
2. Нажмите **Edit this file**.
3. Добавьте объект в JSON-массив, с запятой между соседними объектами. Пример:

   \`\`\`json
   {
     "id": "uterus:new_term",
     "glossary": "uterus",
     "term_en": "new term",
     "term_ru": "русский эквивалент",
     "pronunciation_ru": "НЬЮ тЁРМ",
     "definition_ru": "Краткое определение.",
     "tags": ["anatomy", "uterus"],
     "related": ["uterus:endometrium"]
   }
   \`\`\`

4. ID должен быть уникальным, а \`glossary\` должен совпадать с ID одного из разделов.
5. \`pronunciation_ru\` — приблизительная фонетическая подсказка, не IPA. Проверяйте произношение сложных терминов по надёжному словарю.
6. \`tags\` — массив строк. Одинаковые значения означают общий тег сквозь разделы.
7. В \`related\` указывайте существующие ID. Чтобы сделать переход взаимным, добавьте ID нового термина также в связанный термин.
8. Нажмите **Commit changes**. После публикации Pages обновит сайт.

## Как добавить новый раздел

1. Создайте, например, \`data/terms/neurology.json\` с массивом терминов.
2. Добавьте объект раздела в \`glossaries\` файла \`data/glossaries.json\`:

   \`\`\`json
   {"id":"neurology","name_en":"Neurology","name_ru":"Неврология"}
   \`\`\`

3. Добавьте путь \`terms/neurology.json\` в массив \`term_files\`.
4. Добавьте короткую русскую метку, английскую метку и цвет в объектам \`SHORT\`, \`EN_SHORT\`, \`COLORS\` в \`app.js\`, а цвет раздела — в \`style.css\`.
5. Закоммитьте изменения.

## Проверка сетевых запросов

После первой загрузки все термины находятся в памяти. Смена раздела, алфавитной буквы, раскрытие карточек, открытие related-ссылок, тегов и переходы по истории не должны вызывать дополнительных запросов.

Проверка: открыть DevTools → **Network**, перезагрузить страницу один раз и дождаться загрузки. Затем переключать разделы, буквы и карточки. Новые запросы не должны появляться после начальной загрузки. На iPad Safari можно использовать Web Inspector с Mac.

Сайт не использует сторонние API, CDN, тяжёлые фреймворки, \`fetch\` или Service Workers. JSON загружается через ES5-совместимый \`XMLHttpRequest\`. Для загрузки данных нужен HTTPS-сайт; не открывайте страницу через \`file://\`.
